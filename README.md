# parkinyoung0123.github.io

박인영 님의 업무 포털 (2주 일정 · 할 일 · 업무 웹앱 바로가기).

- 공개 주소: https://parkinyoung0123.github.io
- 접속하면 PIN 잠금 화면이 먼저 나오고, PIN을 넣어야 내용이 보입니다.

## 이 저장소에 없는 것

개인 일정·할일·API 키는 이 저장소에 없습니다. 페이지는 PIN 확인 후 구글 Apps Script API(`박인영_업무포털_API`)에서 그때그때 데이터를 받아 그립니다. 저장소에는 화면 코드만 있습니다.

## 구성

| 파일 | 내용 |
|------|------|
| `index.html` | 잠금 화면 + 2주 보드 + 업무 웹앱 허브 |

## 데이터 쪽

- Apps Script 프로젝트: `박인영_업무포털_API`
- 드라이브 폴더: `박인영_업무포털`
- 스프레드시트: `박인영_할일_DB` (`할일목록`, `설정` 탭)
- PIN은 `설정` 탭 `PIN` 값에서 바꿀 수 있습니다(현재 2580, 반드시 텍스트 형식).
- 일정은 구글 기본 캘린더에서 오늘 기준 이번 주·다음 주를 읽습니다.

## 배포

`main` 브랜치 루트를 GitHub Pages로 배포합니다. `index.html`을 바꾸면 잠시 뒤 자동 반영됩니다.
